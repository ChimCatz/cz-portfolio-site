# temp

A drop folder for files waiting to go into the site: images, certificates,
exports, documents.

- Put a new file here, then say what it is for.
- A file is **moved** into the site when it is used, so anything still here
  has not been used yet. Empty the folder once everything is in.
- Git ignores this folder (only this README is tracked). Nothing in it is
  published or pushed, and it does not reach another computer.
