- Put revisions and new files in the page's folder, then say what they are for.
- A file is **moved** into the site when it is used, so anything still here
  has not been used yet.
- This folder is tracked by git so it syncs between computers, but nothing
  in it is published to the site. **The repo is public:** anything committed
  here can be read on GitHub, so keep private or copyrighted material out.
  Open data (PSA, BLS, ONS tables) is fine.
- Keep file names short. Browser "Save as" names can pass Windows' 260-character
  path limit, and then the file cannot be checked out on another computer.
- The PNG chart images in `about-me/world-data-chart/source-images/` are
  third-party and copyrighted, so git ignores them and they stay on the
  computer they were saved on. `source-links.txt` there says where they came from.
